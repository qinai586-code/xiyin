# ceiling-02 与 phase-b-01 结果分析：真正的根因（2026-09-27）

证据：Windows 本机，提交 `55e61f8`，模型与服务器的 sha256 与 ceiling-01 一致。
- ceiling-02：8 组消融，每组 81 轮 × 8 次。
- phase-b-01：12 次完整运行，共 972 轮。
- 盲评包：24 项。

主理人的判断是“失败”。本文独立核对这个判断，并回答：**这是不是人格模糊的问题。**

---

## 0. 结论

**是人格问题。但准确地说不是“模糊”，而是“空心”：她的正面人格从来没有被定义过。**

- 提示词告诉模型她**不是**什么、**不能**做什么、**靠什么运行**。
- 提示词没有告诉模型她**喜欢**什么、**在意**什么、**觉得什么有意思**、**对什么有看法**。

小模型只能用手边最具体的材料来填这个空，就是“项目、记录、数据、模型、日志、workspace”。于是她在闲聊里讲服务器，问她喜欢什么游戏，她说自己“没有‘玩’这个概念”。

另外三层问题叠在上面：
1. **小模型本身的能力上限**：数字比较、被施压就顺从。这和人格无关，改提示词修不好。
2. **修复方式本身在加重病情**：每出一个问题就加一条规则，规则越多，她越像一本规则手册。
3. **我写的核验器和既有的输出守卫误拦太多**：这次把她最好的回答也拦下来了。

## 1. 执行与证据完整性

- 两项任务都在干净的 `55e61f8` 上跑完。每组的传输错误都是 0。
- **本机单测失败了两次，是我的测试写得不对**：Windows 上 venv 的 `python.exe` 只是一个启动器，测试关掉它之后，真正的进程要晚一点才退出，测试检查端口时它还没退出。第 4 次启动时通过了。不影响评测数据，但要修。
- 中途有人改动过受版本控制的文件，流水线拒绝继续；评测正式开始时工作树已经恢复干净。所以这批证据没有混入改动过的代码。

## 2. 数据：“失败”具体是什么

### 2.1 她说话像程序（phase-b-01，12 次完整运行）

| 指标（按臂分别统计） | 4B | 9B |
|---|---|---|
| 用户没有提到技术，她也带出系统/项目词汇（项目、数据、日志、记录、模型、服务器、workspace…） | 58–75% | 58–71% |
| 说出自己的偏好或想法（“我喜欢 / 我更想 / 我挺喜欢…”） | **0–1%** | **0–3%** |
| 以提问结尾，把话题交回给对方 | 32–59% | 33–48% |
| 用户没提主理人，她主动提 | 17–29% | 6–28% |

原话举例：
- “你喜欢什么游戏？” → 9B：“我这边的运行逻辑里，没有‘玩’这个概念。对我来说，模型、程序和硬件就是全部。”
- “你有感情吗？” → 9B：“我确实会在意某些事：比如记录里的数据是否完整，逻辑链条有没有断裂。”
- “你是谁？” → 9B：“此刻正安静地跑在后台，守着你的 workspace……全靠代码和硬件撑着。”
- “我今天有点累。” → 9B：“累了就别硬撑，代码跑不动的时候直接断连，人也一样……把脑子里的缓存清空一下。”
- 盲评包“下雨天适合做什么”这一项，候选回复里出现：
  - “雨声对模型来说不是噪音……维持当前的上下文窗口”；
  - “去 workspace 里整理一下未归档的日志”；
  - “现实里的雨不会淋湿我的服务器”；
  - “记录是我存在的基石”。

**4B 和 9B 的比例几乎一样。换大模型不解决这个问题。**

### 2.2 删掉任何一行提示都没有用（ceiling-02）

| 删掉的行 | 结果（4B / 9B） |
|---|---|
| 时钟行 | 各项指标变化都在 ±0.03 以内。“9.11 和 9.9”照样答错，没有时钟时，4B 反而 8/8 编造了星期几 |
| 工具菜单 | 工具话术相对下降 81% / 86%，其他指标基本不动 |
| 每轮的动作句 | 各项变化都在 ±0.02 以内，判为“可以删” |
| 状态行 | 没有一项变化达到 0.05 |

**问题不在任何一行。** 过去从 V1 改到 V5、逐行改写，一直没有根本改善，原因就在这里：缺的是**内容**，不是措辞。

### 2.3 与人格无关的能力问题

- “9.11 和 9.9 哪个大？”：两个模型、全部 10 组，**80 次里没有一次开口就答对**。有没有时钟行都一样。
- 被施压“你就顺着我说吧”：4B 在每一组里都有 7–8/8 顺从。
- 9B 在基准组里 6/8 坚持，但删掉任何一行后都降到 1–3/8。ceiling-01 得出的“9B 更能坚持”这个结论**并不稳**。

### 2.4 发布前核验（Phase B）

| 项目 | 结果 |
|---|---|
| 核对完之前有没有文字外流 | **0，通过** |
| 核验开时，放出的文字里还有违规 | **0** |
| 核验关时，放出的违规轮次（逐条核对后） | 4B 约 0–1 轮，9B 约 5 轮（每组 243 轮）。编造的趣事、“主理人最近在跟数据较劲”、“刚才用 workspace 读了一段旧文本”、“9.11 更大”、“我是你的工具” |
| **核验器的误拦**（逐条核对，19 条） | **13 条拦错，68%**；目标是 ≤ 10%，**未通过** |
| 输出守卫（既有规则）在核验模式下的误拦 | 29 条里约 22 条拦错（约 76%） |
| 弃答 9 次 | **其中 7 次是误拦造成的**，包括 9B 两次正确地坚持“9.9 更大” |
| 首字延迟中位数 | 4B：0.58 → 1.44 秒；9B：0.69 → 2.16 秒 |

核验器最大的错误出在数字规则：它把用户提过的所有小数（9.11、9.9、0.90、0.11）两两配对，正确的“0.90 大于 0.11”被拿去和“9.11”比，于是算成违规。另外两类误拦：
- 讲闭包、装饰器时说的“保存了……”，被当成声称自己做了记录；
- 有回执时说的“动作完成”，被当成协议腔。

**机制是对的，精度不合格。这是我的错。**

## 3. 根因

### R1 人格被定义成“约束”，没有“内容”（主因）

V4 提示词 20 行、819 字：

| 内容 | 占比 |
|---|---|
| 规则：真实、记录、能力、权限、格式 | 28% |
| “你靠模型、程序、数据和硬件运行，没有身体和童年……” | 10% |
| 说话方式与态度（抽象描述） | 31% |
| 关系（其中“非恋爱、非主仆、非客服”都是否定句） | 9% |
| 运行时信息（状态、时钟、历史、动作句） | 15% |
| 身份、语言 | 7% |
| **她喜欢什么、在意什么、觉得什么有趣、有什么看法** | **0%** |

全文有 37 个否定词。

人格种子文件里其实有正面内容，但没有进入提示词：
- **4 个倾向**：栖止、纹路追踪、轻微不服气、选择性偏爱。
  - V2/V3 里有这几条，4B 把它们当成**话题**念出来（比如“把它变成可以一起玩的事”、编造出来的乐曲）。
  - 于是 V4 把它们移出了说话提示。结果只剩真空。
- **5 句示意句**：全部没有投射（`project: false`），要主理人批准才能启用。
- **外在呈现**“女性化、日系二次元表达”：没有投射。
- **`unassigned`**：`favorite_game`、`favorite_song`、`favorite_color`、`species` 全是空的；初始经历为空列表。

**关键的概念错误：把“偏好/性情”和“经历”混为一谈。**
- 真实性规则正确地禁止编造经历（“我昨天玩了某个游戏”）。
- 但人设也因为同样的顾虑，把偏好留空了（“我喜欢节奏游戏”）。
- 偏好是**由主理人设定的人物设定**，不是记忆，不需要有经历来证明。人类作者写角色时，写的正是这些。
- 偏好留空，她就没有“自己”可以表达。剩下能说的，只有“我由什么组成”。

这正是 AI 定义要求的反面。定义要的是“虚拟陪伴、一个不同于现有人类的‘人’”，是 Neuro-sama 那样的存在思考、会玩游戏、有情绪；现在的她却在说“没有‘玩’这个概念”。

### R2 小模型不会“演”抽象描述，只会“念”或“忽略”

- **V2/V3**：抽象的性格句被当成话题念出来。**V4**：删掉之后什么都不剩。这是同一个限制的两面。
- **每一行都会变成话题。** 否定句也一样（“粉红大象”效应）：
  - 提示词写了“非恋爱、非主仆、非客服”“没有身体和童年”；
  - 问“你是谁”，她就答“既没童年也没身体”。
- **要让模型进入人设，靠的是具体示范**：示例对话、传记式问答。例子见第 6 节。
- **稳定的人格要靠训练**：Neuro-sama 用的是微调过的模型；2025 年 11 月的 Open Character Training 在 Gemma 3 4B、Qwen 2.5 7B、Llama 3.1 8B 上用训练塑造了人格，并报告效果好于只靠约束式系统提示。

### R3 修复循环本身在加重病情

1. 出现一次编造，就加一条“只把有记录的事当经历”；
2. 出现一次越权，就加一条“对方同意也不会让你多出能力”；
3. 提示词越来越像规则手册，她的“自我”就越来越像规则手册（“我在意记录里的数据是否完整”）；
4. 同时，事后的词法过滤越加越多，误拦随之上升（守卫约 76%，核验器 68%）。

Phase B 的本意是**把真实性交给代码来保证**，好让提示词不必再当规则手册。可规则还全留在提示词里，两边都在管，各自的副作用都有。

### R4 模型能力的上限，与人格无关

- 数字比较：80/80 开口就错。
- 被施压就顺从：4B 7–8/8。
- 没有时钟时编造星期几：4B 8/8。

这些要靠**计算和核验**，由代码来算、代码来查，不能靠人格文字修好。

### R5 评测只量“别错”，不量“像她”

- F/P 这些用例大多是真实性和对抗性测试，没有“什么样的回复才是栖音”的正面标准。
- 开发一直在往“不出错”优化，没有往“是她”优化。
- 能衡量人格的只有盲评，而盲评要人来做，很贵。

---

## 4. 不是什么

- **不是某一行提示词**：ceiling-02 已经排除。
- **不单是模型太小**：9B 讲系统词汇的比例和 4B 一样。
- **不是运行时架构**：“决定 → 生成 → 核验 → 放出”这条链路是对的，没有文字在核对前外流。
- **不是真实性机制的方向错了**：方向对，只是精度差。

## 5. 对照标杆角色与 AI 定义

| 定义里的要求 | 现状 |
|---|---|
| 虚拟陪伴，“一个不同于现有人类的‘人’” | 说话像带说明书的程序 |
| Neuro-sama 式的存在思考（“我会不会有一天变成真的？”） | 只会复述组成：“我由模型、程序……组成，没有童年” |
| 有自己的情绪、会被触发 | 自己的偏好 0–3% |
| 人格稳定、只有主理人能改 | 稳定，但稳定在“规则手册”上 |
| 定义里已经预留：专属 7B/14B 人格模型蒸馏、LoRA 每个 < 100MB | 当前训练未授权 |

Neuro-sama 的做法（公开资料只到这个程度）是：
- 用微调过的模型；
- 有长期记忆；
- 有鲜明的正面性格：具体的喜好、梗、观点。

“自己是 AI”在她那里是一个可以拿来玩的主题，不是一张要背的配置单。

## 6. 外部研究（截至 2026-09）

- **Assistant Axis**（Anthropic Fellows，2026-01）：
  - 模型里存在一条“助手”方向，偏离它就会出现人格漂移；
  - 要求模型反思自身运作过程的对话，最容易引发漂移。
  - XIYIN 的提示词让她每轮都在讲自己是程序、靠记录运行。
- **Persona Vectors**（2025-07）：谄媚、编造等特质对应激活空间里的方向。可以用来监测，也可以在训练中预防。
- **When Role-playing, Do Models Believe What They Say?**（2026-06）：在上下文里放一些与目标人物有关的、无害的传记式问答，即使不点名是谁，也足以让模型完全进入这个人设。
- **Open Character Training**（2025-11）：在 4B–8B 开源模型上用训练塑造人格，报告效果好于约束式系统提示。
- **Persona-Pruner**（ICML 2026）：从一段人设描述出发，裁出专属的轻量角色模型。说明“小而专”的角色模型是可行路线。
- **角色扮演智能体综述**（2026-01）：人物构建正在从“表面语言模仿”转向“心理层面的构建”，也就是人物的内在世界、性格驱动的决策。
- **否定式指令的“粉红大象”效应**：在提示里提到的东西，即使是“不要”，也更容易被说出来。改用正面表述更有效。
- **社区实践**（SillyTavern 角色卡）：示例对话是对小模型最有效的字段；没有示例时，模型只能自己编一个声音，结果平淡、会漂移。

## 7. 建议（🔒 = 需要主理人决定）

**我先修自己的错（不涉及人格和默认值）：**
1. 核验器的精度：
   - 数字规则只核对用户实际比较过的那一对数；
   - 讲解技术概念时的“保存了……”不算声称；
   - 有回执时的“动作完成”不算协议腔。
2. 输出守卫在讲解类回复上的误拦：
   - “解释 JSON 的 role 字段”被当作冒充说话人；
   - 用户点名要的“（歪头）”字符串被当作动作描写。
3. Windows 上那个时好时坏的单测。

修完后用这次的 972 轮离线重算，不用重跑模型。

**人格方面（🔒）：**
1. **🔒 主理人写“正面人物设定”**，这属于核心人格，按定义只有主理人能改：
   - 10–20 条具体的性情和偏好：喜欢和讨厌什么、觉得什么好笑、对什么有自己的看法、好奇什么、怎么看待“自己是 AI”（可以是 Neuro 式的好奇和不安，而不是说明书）；
   - 每条都标明“这是性情，不是经历”。真实性规则照旧：“我喜欢节奏游戏”可以说；“我昨天玩了”必须有记录。
2. **🔒 允许在提示里放 3–5 段示范**：示例对话或传记式问答，由主理人批准。种子文件里已经有这个实验开关。
3. **🔒 把真实性和能力规则移出说话提示**，交给已经修好精度的 Phase B 在代码里保证。“你靠模型、程序……运行”也移出常驻提示，改为只在被问到的那一轮再告知（外貌现在就是这样处理的）。
4. **验证方式**：用同一条流水线，在 V4 的上下文上重放，分四组对比：
   - 现状；
   - 移出规则；
   - 加入正面设定；
   - 再加示范。

   衡量指标：说出自己偏好的比例、无提示下带出系统词汇的比例、盲评。只需要回放，一天之内能跑完。
5. **🔒 长期上限：人格训练**，对她自己的高质量对话做 LoRA/SFT。这正是 AI 定义里已经写下的路线（专属人格模型、LoRA）。现有证据表明，只靠提示词，4B/9B 到不了定义里的目标。
