## 2. 回答主理人的问题

| 可能的原因 | 判断 | 依据 |
|---|---|---|
| 人格设定 | **不是主因** | 同一份人格和提示，3.8 Max 能演得像。设定本身没有自相矛盾，可以实现 |
| 架构 | **不是主因** | 同一套上下文（人格投影、记录、事实、move 行）交给强模型就能用 |
| 模型规模 | **不是主因** | 397B（约 15 倍于 27B）仍明显不如 3.8-27B |
| **模型代际 / 后训练** | **主因** | 3.8 代明显更守边界、更少客服腔。3.5 代从 4B 到 397B 都有同一类毛病 |
| 提示 / 架构的次要诱因 | 存在，值得修 | 三个模型开启话题时都先说“凌晨两点”（时钟和状态行被当成话题）；主理人被当成第三人称；判官抓不到语义编造（27B 的 D-01 在默认模式下会直接放出） |

这里可以对照外部研究：
- “助手默认人格”是模型内部的一个方向，后训练会改变它；
- 新一代模型的后训练恰恰改进了这一点。

## 3. 对本地 12GB 的含义

- **3.8-27B 是目前唯一有官方 GGUF、而且测下来明显更好的本地候选。** 但它还有硬失败，要配合两样东西：
  - 整段核验（hold）：它能抓 D-01 这类封闭类说法；
  - 第 2 节里的小修。
- **速度问题：** 12GB 显存装不下 27B，只能部分放到内存，估计每秒 3–6 token，一条回复要 20–40 秒。文字聊天勉强可以，语音不行。要流畅，需要 24GB 显存，或者等 Qwen3.8 出官方小模型。
- **第三方蒸馏的 Qwen3.8-9B 等模型**：没有官方背书，质量未知，只能先测再说。
